# もしあの時 - 朝の西友3点セット MVP

スマホ向け静的Web MVPです。サーバー不要で、データはブラウザの localStorage に保存します。

## 実装済み
- 朝の「お菓子 + 昼メシ + 飲み物」3点セット提案
- 1カテゴリ固定 + 残りで価格・kcalを調整
- 別セット提案
- JAN/EANバーコード読み取り（BarcodeDetector対応ブラウザ）
- JAN手入力フォールバック
- 商品別の代替候補
- 日別の購入/食べたもの履歴
- 「よかった / 微妙 / もう買わない」フィードバック
- NG商品を次回提案から除外
- 商品別の提案採用率・購入回数・良/後悔件数
- PWA manifest

## 起動
カメラを使う場合は HTTPS または localhost で開いてください。

```bash
python3 -m http.server 8080 -d .
```

ブラウザで http://localhost:8080/ を開きます。

## 試用JAN

- 4900000000105: カツ丼
- 4900000000201: コーラ 500ml
