# seiyu-asa / もしあの時

毎朝の西友で買う **お菓子 + 昼メシ + ペットボトル** を、価格・カロリー・過去の満足度から提案するスマホ向けWeb MVPです。

## 実装済み

- 朝の3点セット提案
- 好きな1カテゴリを固定して残りを調整
- JAN/EANバーコード読み取り（BarcodeDetector対応ブラウザ）
- JAN手入力フォールバック
- 未登録JANを Open Food Facts で補完
- 店頭価格 / 西友ネットスーパー参考価格 / kcal の登録と比較
- 西友ネットスーパー公開見学ページ検索用 Cloudflare Pages Function
- 同カテゴリの代替候補
- 日別の「買う予定 / 食べた」履歴
- 「よかった / 微妙 / もう買わない」
- NG商品の次回提案除外
- 商品ごとの提案回数・採用回数・選ばれ率
- localStorage保存

## 起動

静的UIだけなら:

    python3 -m http.server 8080

カメラは HTTPS または localhost が必要です。

西友検索APIまで使う場合は Cloudflare Pages / Wrangler で起動してください。
Pages Function は functions/api/seiyu/search.js です。

## 価格データ

西友ネットスーパー側は公開見学ページにも商品名・価格がありますが、実際の品揃え・価格はログイン後の配送エリア等で変わります。
そのためこのMVPでは:

- storePrice: 実店舗で確認した価格
- netPrice: 西友ネットスーパー参考価格
- kcal: JAN商品DBまたはユーザー登録値

として分けています。
